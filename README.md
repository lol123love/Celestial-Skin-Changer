## 📖 What is this?

Originally, the Celestial app has an internal "Skin-Hack Filter." They heavily restrict tool usage scanning your custom mods and blocking them or moving them to a quarantine folder if they don't like what they see.

This project completely transforms the Celestial app into a **totally different application**: a fully unlocked, unrestricted custom skin changer. 

The launcher acts as a middleman. When Celestial tries to check or restrict a mod, this bypass intercepts the internal checks and forces the app to accept everything. This allows you to use *any* custom skin or mod without being micromanaged by the original developers.
